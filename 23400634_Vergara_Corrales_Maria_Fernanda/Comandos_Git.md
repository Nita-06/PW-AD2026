1. git init

Inicializa un nuevo repositorio Git local en la carpeta donde estás ubicado.

2. git clone

Descarga y copia un repositorio remoto ya existente a tu equipo local.

3. git status

Muestra el estado del área de trabajo, incluyendo archivos modificados, pendientes o en el área de preparación.

4. git add

Agrega archivos o cambios específicos al área de preparación (staging area) para incluirlos en el próximo commit.

5. git commit

Guarda de forma permanente los cambios preparados en el historial del repositorio local. Se usa habitualmente con -m "mensaje".

6. git log

Muestra la lista e historial de commits realizados en la rama actual.

7. git diff

Compara y muestra las diferencias exactas de código entre archivos antes de agregarlos o guardarlos.

8. git branch

Muestra las ramas disponibles en el repositorio o crea una nueva rama si le agregas un nombre.

9. git switch

Cambia de una rama a otra dentro del proyecto (o con -c crea y se cambia a una nueva rama).

10. git merge

Combina el historial y los cambios de una rama secundaria dentro de la rama donde te encuentras posicionado.

11. git fetch

Descarga el historial y la información de un repositorio remoto sin aplicar cambios a tus archivos locales.

12. git pull

Obtiene las actualizaciones del repositorio remoto y las fusiona inmediatamente en tu rama local actual.

13. git push

Sube tus commits locales hacia el servidor o repositorio remoto (como GitHub o GitLab).

14. git restore

Deshace cambios en archivos del área de trabajo o los quita del área de preparación.

15. git stash

Guarda temporalmente los cambios sin realizar un commit para que puedas trabajar con un directorio limpio y restaurarlos después.
